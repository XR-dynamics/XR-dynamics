What it does

From your fingertips to the robot's.

One interaction layer, three jobs: handle virtual objects naturally, control a robot with the same hands, and use the simulation to practise before anything moves in the real world.

01

Natural Object Interaction

Our XR grab plugin lets users pick up, hold, rotate, and position virtual objects with tracked hands.

02

Precision Robot Control

We’re developing a robotics plugin that translates operator input into controlled robot movements for remote manipulation and operations.

03

Simulation & Training

Use the virtual environment to rehearse tasks, develop interaction workflows, and explore how human demonstrations can support robot learning.
